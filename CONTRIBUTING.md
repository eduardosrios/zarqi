# Contributing

Thank you for your interest in zarqi.

This is a proprietary project. Contributions are accepted only when explicitly requested or approved by the repository owner.

## Contribution Guidelines

- Use English for all content, comments, documentation, commit messages, and pull request descriptions.
- Keep the project stack to plain HTML, CSS, and JavaScript unless the owner approves a change.
- Do not add React, build tooling, package managers, or frameworks unless explicitly requested.
- Keep changes focused on final website files and required repository governance files.
- Do not add local notes, prompt files, downloaded references, screenshots, archives, or unrelated Markdown files.
- Do not add Codex as a contributor.

## Pull Requests

Before opening a pull request, confirm that the change is authorized by the owner. A pull request should include:

- A clear summary of the change.
- The reason the change is needed.
- Any manual testing performed.
- Screenshots for visual changes, when relevant.
